# 💻 Example Execution Script

This directory contains an executable example demonstrating how the graph coloring algorithms implemented in the core source code are utilized in practice. Separating the execution logic from the core modules ensures a clean, modular architecture.

### 📄 Contents:
* **`graph_coloring_task.py`** - The primary demonstration script. When executed, it generates a sample graph, applies the implemented exact and heuristic coloring algorithms, and outputs the performance metrics and results directly to the console.

### 🚀 How to Run
To execute this example, navigate to the root directory of the repository in your terminal and run:

```bash
python src/example/graph_coloring_task.py
```

(Refer to the main repository documentation for details on passing custom parameters like node count or edge probability).
