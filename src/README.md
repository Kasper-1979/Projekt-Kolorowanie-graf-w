# 💻 Source Code (`src`)

This directory serves as the root container for all Python source code related to the Graph Coloring Optimization project. 

The codebase is strictly organized into separate modules to adhere to Clean Architecture principles, ensuring that executable demonstration scripts are completely isolated from the core computational engine.

### 📁 Directory Structure:

* **`/main`** - Contains the core algorithmic logic, including exact (Brute Force, Backtracking) and heuristic (LF, SL, DSATUR) graph coloring implementations.
* **`/example`** - Contains executable demonstration scripts that utilize the core modules to run benchmarks and generate performance metrics.

> **Navigation Note:** Each subdirectory contains its own dedicated `README.md` file with deeper technical details regarding its specific contents and instructions on how to run the code.
