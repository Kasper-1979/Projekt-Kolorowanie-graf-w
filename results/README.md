# 📊 Test Results & Performance Metrics

This directory contains the raw data, compiled benchmarks, and visualizations from the execution of the graph coloring algorithms. 

The tests compare both exact (Brute Force, Backtracking) and heuristic (LF, SL, DSATUR) approaches in terms of:
* **Execution Time (Computational Complexity)** 
* **Algorithm Optimality (Achieved Chromatic Number)**

### 📁 Contents:
* **`graph_coloring_tests_results1.xlsx` / `.pdf`** - Performance metrics, data tables, and visualizations for the first test scenario.
* **`graph_coloring_tests_results2.xlsx` / `.pdf`** - Performance metrics, data tables, and visualizations for the second test scenario (e.g., varying node counts and edge densities).

> **Note:** The `.pdf` files are provided for quick, accessible previewing of the charts and analytical summaries directly within the browser, while the `.xlsx` files contain the raw, filterable datasets for deeper evaluation.
